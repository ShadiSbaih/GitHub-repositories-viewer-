# GitHub API Fetcher

A simple web application to fetch and display GitHub repositories for a given username using the GitHub API. It includes a dark mode feature to toggle between light and dark themes.

## Features

- Fetch GitHub repositories by username.
- Display repository details including name, description, owner, and language.
- Dark mode toggle to switch between light and dark themes.
- Loading overlay while fetching data.

## Technologies Used

- HTML
- CSS
- JavaScript
